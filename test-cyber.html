Cybersecurity Basics Test

Answer the following questions to test your knowledge in cybersecurity basics.

Note: These questions are based on the first 20 levels of OverTheWire: Bandit

1. What command is used to connect to a remote server via SSH on a specific port?

2. Which command lists all files in a directory, including hidden ones?

3. What command is used to search for a file based on it's size and type?

4. What command rotates "characters" by 13 positions?

5. You encounter a compiled binary file that you suspect contains a readable password string, but running cat on it dumps unreadable control codes and terminal garbage. Which core utility should you use to extract printable text sequences from the binary?

6. You need to extract lines containing the word "critical" from a system log file named sys.log, exclude any of those lines that also contain the word "debug", and save the final cleaned results into a new file named alerts.txt. Which command achieves this?

7. You need to connect to a local server running on port 30001 that requires an encrypted SSL/TLS negotiation before it transmits a password token. Which tool is widely used for this client interaction?

8. Which tool/command can be used to communicate with ports and listen for incoming connections?

9. Which tool is used to check open ports on a remote host?

10. What tool is used to compare two files or directories side by side?
